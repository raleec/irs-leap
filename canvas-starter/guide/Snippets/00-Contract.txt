CUSTOM API
Unique name: leap_GetAnnualTotal
Unbound action (not a Web API function-only operation).
Inputs:
  RequesterId  Text containing a Dataverse systemuserid GUID, not Entra GUID.
  CalendarYear Whole number integer of LEAVE year.
Outputs:
  TotalHours        Known approved hours, adding each row independently.
  MissingHours      Number of approved rows with null/blank Leave Hours.
  ApprovedRequests  Count of all approved rows, including blanks and zeros.
  RequesterName     Authorized target requester's display name.
The calling principal must be the current Canvas user. Self is allowed.
Otherwise the caller must be a selected approver on ANY saved request for that
requester, regardless of request year or status. This is lifetime requester-level
authorization: selection in one year authorizes aggregates for other years too.
CalendarYear limits aggregation, NOT the authorization relationship.
An approver may receive employee-wide approved aggregate without hidden details.
The API must deny unrelated users before privileged aggregation.
Never call it through F's owner-connected flow to emulate end-user totals.

SECURITY MINIMUM (VERIFY ACTUAL IMPORTED ROLES AND PRIVILEGES)
E, A, B, U:
  Request Create and user-level Read (plus appropriate create lookup Append /
  Users Append To privileges). NO request Write/Delete, Assign, or broad Share.
  Read only their own or explicitly shared authorized records.
  Read sufficient Users metadata for native lookup and own identity resolution.
  Execute API under caller identity with server authorization.
Selected approvers:
  Server grants row-specific Read access; app sharing alone does not do this.
F:
  Dedicated authorized automation identity. Request Read/required restricted
  Write and required Users Read plus connector/approval/email permissions.
  Plug-in authorization for F must match the starter configuration.
  No participant access to F's connection credentials, and no System Admin as
  a permanent service-account shortcut.
Administrator:
  Separate deployment/role/audit/operations responsibility; do not use as UAT E.

SEMANTICS
One category + one selected date per row; separate rows for cross-day leave.
Overlaps and repeated dates are allowed and must not be deduplicated in totals.
Hours is independently entered, never calculated from minutes.
Blank != zero. Approved blank increments MissingHours; explicit zero does not.
Calendar Year derives from Leave Date, not Created On or Decided On.
